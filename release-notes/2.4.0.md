## A new look, an export queue, and Wallpaper Engine round trips

### New
- **Export queue**: keep editing while exports run one after another. Export becomes **Add to queue** while something is running, the sidebar lists what's next (remove, Start, Clear), and the queue is kept when OLEDable closes. A new setting resumes it by itself when the app opens.
- **Smart Export button**: for a video that's already exporting or queued, it shows **Exporting…** / **Queued**. Change something and it becomes **Export again with changes** (stop and restart, or export again after it finishes) or **Update queued export**.
- **Add to Wallpaper Engine**: send a result back to Wallpaper Engine as a wallpaper of its own, with the original's sound. Turn it on in the editor (even mid-export), or use the button in the Library for videos you've already converted. Adding again updates the same copy; Workshop wallpapers are never touched.
- **Live previews**: the selected tile plays, in both the Library and the Wallpaper Engine page, including the video inside a scene.
- **Output sizes**: 4K, 1440p and 1080p are now one click each; Custom keeps your own size and the Fold 8 Ultra presets. The Library shows every video's size (HydroShift, 4K, 1440p…).
- **New logo and font**: the Eclipse logo (sidebar, taskbar, installer) and Manrope throughout the app.

### Better
- The Library works like the Wallpaper Engine page: select a video, then Edit, Add to Wallpaper Engine or its folder at the top right.
- Open and edit the next wallpaper while an export runs (copying from Wallpaper Engine no longer waits).
- Scenes with a video inside are found in every texture layout, so more of them offer **Use its video**.
- The app and installer are signed (publisher: Jesse Sievers), so Windows and antivirus software trust them more.
- Faster start: video details are remembered, so the Library doesn't re-read every file each time. The Wallpaper Engine page opens at once.
- Exports run at lower priority, so the editor stays smooth while they work.
- More reliable: helper programs end with the app, settings can't be left half-saved, unexpected errors are logged, closing during a job asks first, and only one OLEDable runs at a time.
- The Black level tooltip explains that true black can cost shadow detail.
- New videos start at their Original size.
